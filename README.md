# Fajrix® — GitHub organisation and community guidance

This repository provides the public organisation profile, Fajrix brand assets and shared community guidance for the [Fajrix GitHub organisation](https://github.com/FajrixUK).

**Looking for Fajrix?** Start with the [public organisation profile](profile/README.md), which is displayed at [github.com/FajrixUK](https://github.com/FajrixUK). The profile introduces our financial technology direction and links to public research, engineering principles and ways to connect. This repository's root README instead documents community and governance resources.

## Public work and research

- [Fajrix Research](https://github.com/FajrixUK/research) provides the public agenda, methodology and publication register for applied research into financial intelligence, resilient systems and trustworthy AI.
- [Fajrix Engineering](https://fajrix.com/engineering) explains the engineering principles that inform the company's development.
- [Fajrix platform direction](https://fajrix.com/features) describes what is being built. The accounting platform itself is developed separately and is not released as source code by this repository.

The existence of an agenda or experimental prototype does not establish product availability or validated research findings.

## Participation, assurance and reuse

Public documentation changes should follow [contribution guidance](CONTRIBUTING.md), with evidence for factual claims and appropriate review of external links, accessible presentation, privacy and publication rights. Automated [documentation checks](.github/ci/README.md) help detect formatting and local-link errors; they do not establish factual correctness or accessibility conformance.

Report vulnerabilities through [private security channels](SECURITY.md), not public issues. Report accessibility barriers through the routes described in our [accessibility statement](ACCESSIBILITY.md).

This repository is public but is **not** made available under a blanket open-source or Creative Commons licence. See the [rights notice](LICENSE.md) and [brand guidance](BRAND_ASSETS.md) before reusing material.
