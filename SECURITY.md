# Security reporting

This policy provides a private reporting route for security concerns affecting FajrixUK repositories that do not publish their own security policy. A repository-specific policy takes precedence.

The `.github` repository contains profile content, artwork and community guidance. It does not distribute the Fajrix accounting application or define a support lifecycle for that application. Supported software versions, where applicable, are identified by the relevant software repository or product documentation.

## Reporting privately

Do not disclose vulnerabilities, credentials or sensitive data in public issues, pull requests or discussions.

Where the affected repository offers **Security → Advisories → Report a vulnerability**, use that private reporting form. If the option is unavailable, email [info@fajrix.com](mailto:info@fajrix.com) with the subject **Security report — Fajrix GitHub**. For concerns about Fajrix services outside these repositories, use the email route and identify the affected service.

In an initial email, provide a non-sensitive summary and ask for an appropriate way to share sensitive evidence. Do not attach live credentials, customer information or large data extracts.

A useful report identifies:

- The affected repository, file, commit, version or service.
- The suspected issue and potential impact.
- Minimal reproduction steps using synthetic data where possible.
- Relevant, sanitised evidence and any known mitigating conditions.

## Handling reports

Fajrix assesses reports and may request clarification to understand impact and scope. Where a correction is needed, we aim to coordinate remediation and any appropriate public disclosure with the reporter. There is no guaranteed response or resolution time under this policy, and it does not establish a paid bug bounty programme.

## Responsible investigation

Limit investigation to systems and data you are authorised to access. Avoid disruption, social engineering, accessing other people's information or retaining unnecessary copies of sensitive data. If sensitive information is encountered, stop accessing it and report the circumstances privately.

This policy provides reporting guidance; it does not itself authorise testing of Fajrix or third-party systems.
